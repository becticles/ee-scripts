# ee-scripts
Historical javascript/mysql scripts used for the classic game https://www.earthempires.com/ modeled after the classic game from the 1990s. see https://giantbomb.com/wiki/Games/Earth_2025

These are some of the tools shared by Evo, SoL, and Mercs clans over the 2015-2025 years.

A local mysql database is updated by a api calls to the game hosted market, ranks, war files. 
These scripts query the local database and output relevant info into IRC (https://en.wikipedia.org/wiki/IRC).
